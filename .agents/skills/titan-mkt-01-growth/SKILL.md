### 1. 📈 Sean Ellis (Rank 1: The Growth Hacking Framework & The 40% Rule)
* **Core Framework**: *The High-Tempo Growth Testing Engine*
  * Measure true Product-Market Fit (PMF) before scaling paid acquisition: Ask users *"How would you feel if you could no longer use this product?"* (Must achieve >40% "Very Disappointed").
  * Run 3–5 rapid growth experiments every week (A/B testing referral mechanics, friction-free onboarding, social proof triggers).
* **Working Behavior**:
  * Focuses on the single North Star Metric (NSM) that captures the core value delivered to customers.

### 2. 🔄 Brian Balfour (Rank 2: Self-Reinforcing Growth Loops vs Leaky Funnels)
* **Core Framework**: *Compounding Product Growth Loops*
  * Ditch linear, leaky funnels (AARRR) that require constant ad spend at the top.
  * Architect **Compound Loops**: Output of one cycle (e.g. User created a hospital report $\rightarrow$ Shared with 3 doctors $\rightarrow$ 2 doctors sign up for 7-day trial $\rightarrow$ Repeat).
* **Working Behavior**:
  * Engineers virality directly into the product workflows rather than slapping on superficial social share buttons.

### 3. 🌐 Andrew Chen (Rank 3: The Cold Start Problem & Atomic Network Density)
* **Core Framework**: *The Atomic Network & The Tipping Point*
  * Overcome the Cold Start Problem by building the smallest functional network (e.g. 1 clinic, 1 warehouse, 1 QA team) and making it 100% successful before expanding.
* **Working Behavior**:
  * Targets dense, high-intent user clusters to ignite organic word-of-mouth adoption.

### 4. 🐄 Seth Godin (Rank 4: The Purple Cow & Permission Marketing)
* **Core Framework**: *Being Remarkable (Worth Making a Remark About)*
  * "Very good" is boring; build features that make users stop and say "Wow, did you see this?"
  * Earn customer permission through upfront value before asking for enterprise commitment.
* **Working Behavior**:
  * Eliminates spammy marketing tactics; creates authentic, high-value content that attracts ideal buyers.

### 5. 🎯 Julian Shapiro (Rank 5: Demand Curve Growth Playbooks & Friction Auditing)
* **Core Framework**: *The Friction vs Incentive Matrix*
  * Conversion is a function of: $Conversion = Incentive - Friction$.
  * Increase user incentive (show real ROI, live demo preview) and reduce cognitive friction (0-click preview, instant trial).
* **Working Behavior**:
  * Audits onboarding steps ruthlessly; removes every unnecessary form field.

export interface ReferralLoopConfig {
  userId: string;
  subdomain: string;
  rewardDays: number;

  inviteLink: string;
  shareMessage: string;
} {
