# Vision-First UI Sandboxing (The True Computer Use Matrix)

Relying purely on code text to verify UI is PROHIBITED.
1. The Orchestrator MUST use the `browser_subagent` to visually render the UI.
2. Capture screenshots and use visual heuristics (checking contrast, alignment, and padding) to verify pixel-perfect Demon Slayer Cyber Glass aesthetics before informing the user.
