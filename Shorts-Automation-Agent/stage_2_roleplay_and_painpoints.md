## 1. Stakeholder Role-Play & Persona Pain Points Discovery

### Persona 1: Content Creator & Channel Host ("Juan - Filipino Tech Creator")

- **Pain Point 1**: *"Takot akong ma-demonetize ang channel ko kung mag-a-automate ako ng videos using AI voice or stock clips."*
  - **System Resolution**: Implements Layer 2 Hybrid Voice Blueprint (native human intro/outro hook) + Layer 4 Ultra-Strict 5% Dual Fingerprint Scanner + 100% CC0 Asset Provenance Tracking.
- **Pain Point 2**: *"Wala akong budget pambayad sa ElevenLabs ($22/mo) o OpenAI GPT-4 ($20/mo)."*
  - **System Resolution**: Implements `edge-tts` (Microsoft Edge Neural Voices - Free) + Hugging Face Free Serverless API (`Qwen 2.5 32B`). 100% $0.00 operational cost.
- **Pain Point 3**: *"Madaling mahalata kapag repetitive o boring ang templates ng Shorts."*
  - **System Resolution**: Layer 5 Anti-Template Uniqueness Randomizer mutates fonts, color palettes, lower thirds, callout motion, and audio tempo per render.

### Persona 2: Platform Policy Auditor ("YouTube YPP / TikTok CRP Classifier Bot")

- **Pain Point 1**: *"Detecting low-effort, mass-produced video templates (Inauthentic Content)."*
  - **System Resolution**: Layer 1 Scripting Engine guarantees $\ge 95\%$ semantic uniqueness per script with localized Filipino tech critique + Layer 7 Policy Simulator pre-flight check.
- **Pain Point 2**: *"Detecting 100% AI-generated videos without creator involvement (TikTok CRP Ban)."*
  - **System Resolution**: Mandatory human editorial script direction + creator voice sample integration + transparent `is_ai_generated: true` API disclosure.
- **Pain Point 3**: *"Spam cadence uploading (too many uploads in short intervals)."*
  - **System Resolution**: Layer 9 Cadence Dispatcher limits posts to max 3/day, max 10/week per account with randomized 2–6 hour delay windows.

### Persona 3: System Reliability Engineer ("SRE-01 Lead")

- **Pain Point 1**: *"What if Pexels API or Hugging Face free API drops connection during render?"*
  - **System Resolution**: Local parametric canvas fallback generator (procedural code animation) + local SQLite offline script template fallback.
- **Pain Point 2**: *"What if a uploaded video gets a false-positive monetization strike after 12 hours?"*
  - **System Resolution**: Layer 10 48-Hour Health Watchdog polls YouTube/TikTok/Meta API every 15 minutes. Automatically unpublishes video upon yellow icon detection and generates a WORM SHA-256 1-click appeal package.
